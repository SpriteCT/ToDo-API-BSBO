# Telegram Bot для управления задачами

Telegram бот для работы с ToDo API через удобный интерфейс мессенджера.

## 📁 Структура

- `bot.py` — основной файл с логикой бота (команды, FSM диалоги, напоминания)
- `api_client.py` — HTTP клиент для взаимодействия с Backend API
- `config.py` — конфигурация (токен бота, URL API)
- `Dockerfile` — образ для запуска в Docker

## 🚀 Запуск

### Через Docker Compose (рекомендуется)

Из корня проекта:
```bash
docker-compose up --build bot
```

### Локальный запуск

1. Установите зависимости:
```bash
cd bot
pip install aiogram httpx python-dotenv
# или используйте requirements.txt из backend
pip install -r ../backend/requirements.txt aiogram
```

2. Настройте переменные окружения в `.env` (в корне проекта):
```bash
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
API_BASE_URL=http://localhost:8000/api/v3  # опционально, по умолчанию используется это значение
```

3. Запустите бота:
```bash
python -m bot.bot
```

## 📋 Команды бота

### Справка
- `/start` — приветствие и список всех команд
- `/help` — подробная помощь

### Авторизация
- `/register` — регистрация нового пользователя
  - Пошаговый диалог: никнейм → email → пароль
  - Email валидируется перед отправкой на сервер
- `/login` — вход в аккаунт
  - Пошаговый диалог: email → пароль
  - После успешного входа сохраняется JWT токен
- `/logout` — выход из аккаунта
- `/me` — информация о текущем пользователе (id, nickname, email, role)

### Настройки
- `/timezone <сдвиг>` — установить часовой пояс
  - Примеры: `/timezone +3`, `/timezone -5`
  - Диапазон: от -12 до +14 часов
  - Влияет на ввод дедлайнов (время вводится в вашем локальном времени)
- `/change_password` — смена пароля
  - Пошаговый диалог: старый пароль → новый пароль

### Просмотр задач
- `/tasks` — список всех ваших задач
  - Показывает ID, статус (✅/⏳), название, описание, квадрант, дедлайн
- `/today` — задачи с дедлайном на сегодня
- `/search <текст>` — поиск задач по названию и описанию
  - Пример: `/search отчет`

### Управление задачами
- `/newtask` — создать новую задачу
  - Пошаговый диалог:
    1. Название задачи
    2. Описание (или `-` если без описания)
    3. Важность (да/нет)
    4. Дедлайн в формате `ГГГГ-ММ-ДД ЧЧ:ММ` (в вашем локальном времени) или `-` если без дедлайна
- `/edittask` — изменить существующую задачу
  - Пошаговый диалог:
    1. ID задачи для редактирования
    2. Новое название (или `-` чтобы оставить без изменений)
    3. Новое описание (или `-` чтобы оставить без изменений)
    4. Новый дедлайн (или `-` чтобы оставить без изменений)
- `/complete <id>` — отметить задачу выполненной
  - Пример: `/complete 5`
- `/delete <id>` — удалить задачу
  - Пример: `/delete 5`

## 🔔 Напоминания

Бот автоматически напоминает о задачах с приближающимся дедлайном:
- Проверка выполняется каждые **5 минут**
- Напоминания отправляются для задач с дедлайном **0-1 день** до истечения
- Напоминания работают только для авторизованных пользователей

## 🌍 Часовой пояс

Бот поддерживает работу с локальным временем пользователя:
1. Установите свой часовой пояс командой `/timezone <сдвиг>`
2. При создании/редактировании задач вводите время в **вашем локальном времени**
3. Бот автоматически конвертирует его в UTC для отправки на сервер

**Пример:**
- Установлен часовой пояс UTC+3
- Вводите дедлайн: `2025-12-31 18:00`
- Бот сохранит в БД: `2025-12-31 15:00 UTC`

## 🔐 Безопасность

- JWT токены хранятся в памяти процесса (не сохраняются на диск)
- При перезапуске бота все сессии сбрасываются (нужно войти заново)
- Пароли никогда не сохраняются, только хеши отправляются на сервер

## 🛠️ Технологии

- **aiogram 3.x** — фреймворк для Telegram ботов
- **httpx** — асинхронный HTTP клиент
- **FSM (Finite State Machine)** — для многошаговых диалогов

## ⚙️ Переменные окружения

- `TELEGRAM_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather) (обязательно)
- `API_BASE_URL` — базовый URL Backend API (по умолчанию: `http://localhost:8000/api/v3`)

## 🔧 Разработка

### Структура кода

- **FSM States** — состояния для многошаговых диалогов (регистрация, логин, создание задачи и т.д.)
- **SESSIONS** — словарь для хранения JWT токенов пользователей (chat_id → UserSession)
- **TIMEZONE_OFFSETS** — словарь для хранения часовых поясов пользователей (chat_id → offset)
- **reminders_worker** — фоновый воркер для отправки напоминаний

### Добавление новой команды

1. Создайте обработчик в `bot.py`:
```python
@router.message(Command("mycommand"))
async def cmd_mycommand(message: Message) -> None:
    session = await _require_session(message)
    if not session:
        return
    # Ваша логика
```

2. Добавьте команду в список в `/start` и `/help`

3. Обновите описание команды для BotFather (см. корневой README)

## 📞 Поддержка

При возникновении проблем проверьте:
1. Правильность токена бота в `.env`
2. Доступность Backend API по адресу из `API_BASE_URL`
3. Логи контейнера: `docker-compose logs bot`
